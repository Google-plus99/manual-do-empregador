INSTITUTO FELIPE LOPES: PORTAL DE INFOPRODUTOS
Cloudflare (hospedagem, gratuita) + Supabase (pedidos, licenças, contatos e PDFs, gratuito)
+ Mercado Pago (Checkout Pro, Pix, taxa por venda) + Resend (e-mail, gratuito)

O passo a passo completo e explicado está no documento "Guia completo: colocar o portal no ar".
Resumo:

COMO FUNCIONA A COMPRA
   O cliente informa nome e e-mail, é levado à página do Mercado Pago, paga com Pix e volta
   para /obrigado, onde baixa os PDFs e recebe a chave do simulador. O mesmo vai por e-mail.
   QR Code dentro do site: pronto e desligado (pagamento: "pix-no-site" em assets/app.js).

1) MERCADO PAGO
   Suas integrações > Criar aplicação > Pagamentos online > sem e-commerce > Checkout Pro.
   Credenciais de produção > Ativar. Copie o Access Token (APP_USR-...). A conta precisa de chave Pix.

2) SUPABASE
   New project (região São Paulo) > SQL Editor > cole supabase/schema.sql > Run.
   Storage > produtos > envie manual-do-empregador.pdf e cartilha-do-bom-fornecedor.pdf.
   Project Settings > API: copie a Project URL e a chave service_role.

3) CLOUDFLARE (plano Free, permite venda)
   a. Crie a conta em dash.cloudflare.com.
   b. Workers & Pages > Create application > Import a repository > GitHub > manual-do-empregador.
      Project name: instituto-felipe-lopes (igual ao "name" de wrangler.jsonc).
      Build command: vazio. Deploy command: npx wrangler deploy. Save and Deploy.
   c. Projeto > Settings > Variables and Secrets > Add, tipo Secret, uma por uma:
        MP_ACCESS_TOKEN            Access Token de produção do Mercado Pago
        SUPABASE_URL               Project URL do Supabase
        SUPABASE_SERVICE_ROLE_KEY  chave service_role do Supabase
        LIC_CHAVE_PRIVADA          a linha {"kty":"EC"...} do arquivo chave-privada-licencas.txt
        URL_SITE                   primeiro https://instituto-felipe-lopes.<sua-conta>.workers.dev
        LIC_DOMINIO                o mesmo endereço, sem https://
      Clique em Deploy depois de adicionar.

4) TESTE
   Peça ao Claude os preços em R$ 1,00, compre cada oferta no endereço .workers.dev
   e confira a volta para /obrigado, os downloads, a chave e Supabase > pedidos.

5) DOMÍNIO institutofelipelopes.com.br
   Cloudflare > Add a domain > institutofelipelopes.com.br > plano Free.
   Copie os 2 servidores de nome (nameservers) que a Cloudflare mostrar.
   Registro.br > domínio > DNS > Alterar servidores DNS > cole os 2 e salve. Espere ficar Active.
   Workers & Pages > projeto > Settings > Domains & Routes > Add > Custom domain:
   institutofelipelopes.com.br e www.institutofelipelopes.com.br.
   Atualize URL_SITE (https://institutofelipelopes.com.br) e LIC_DOMINIO (institutofelipelopes.com.br).

6) E-MAIL DE ENTREGA (Resend)
   resend.com > Domains > Add Domain > institutofelipelopes.com.br.
   Crie os registros mostrados em Cloudflare > institutofelipelopes.com.br > DNS > Records
   (ou use o botão de configuração automática da Cloudflare, se o Resend oferecer). Verify.
   API Keys > Create > adicione RESEND_API_KEY e EMAIL_REMETENTE como Secret na Cloudflare.

Preços, produtos e combos: assets/catalogo.js. WhatsApp: assets/catalogo.js.
E-mail, dados da empresa e modo de pagamento: bloco CONFIG em assets/app.js.
Toda alteração enviada ao GitHub é publicada sozinha pela Cloudflare em cerca de 1 minuto.
