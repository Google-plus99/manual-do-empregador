INSTITUTO FELIPE LOPES: PORTAL DE INFOPRODUTOS
Vercel (hospedagem) + Supabase (pedidos, licenças, contatos e PDFs) + Mercado Pago (Pix)

1) MERCADO PAGO
   Suas integrações > Criar aplicação > Checkout Transparente > Ativar credenciais de produção.
   Copie o Access Token (APP_USR-...). A conta precisa ter chave Pix cadastrada.

2) SUPABASE
   a. Crie um projeto (região South America, São Paulo).
   b. SQL Editor > New query > cole supabase/schema.sql > Run.
   c. Storage > bucket "produtos" (privado) > envie os PDFs com estes nomes exatos:
        manual-do-empregador.pdf
        cartilha-do-bom-fornecedor.pdf
   d. Project Settings > API: copie a Project URL e a chave service_role.

3) VERCEL
   a. Add New > Project > importe o repositório > Framework Preset "Other" > Deploy.
   b. Settings > Environment Variables:
        MP_ACCESS_TOKEN            Access Token de produção do Mercado Pago
        SUPABASE_URL               Project URL do Supabase
        SUPABASE_SERVICE_ROLE_KEY  chave service_role do Supabase
        LIC_CHAVE_PRIVADA          chave privada JWK do gerador de licenças
        URL_SITE                   primeiro https://<projeto>.vercel.app, depois o domínio
        LIC_DOMINIO                mesmo endereço de URL_SITE, sem https://
        RESEND_API_KEY             chave da API do Resend (e-mail de entrega)
        EMAIL_REMETENTE            Instituto Felipe Lopes <contato@institutofelipelopes.com.br>
   c. Deployments > Redeploy.

4) TESTE
   Peça para colocar os preços em R$ 1,00 (assets/catalogo.js), compre cada oferta com seu Pix
   e confira em Supabase > Table Editor > pedidos.

5) DOMÍNIO institutofelipelopes.com.br
   Vercel > Settings > Domains > adicione institutofelipelopes.com.br e www.institutofelipelopes.com.br.
   No registro.br, em DNS do domínio, crie os registros que a Vercel mostrar.
   Atualize URL_SITE e LIC_DOMINIO e faça Redeploy.

Preços, produtos e combos: assets/catalogo.js (vale para o site e para a cobrança).
WhatsApp: assets/catalogo.js. E-mail e dados da empresa: bloco CONFIG em assets/app.js.

E-MAIL DE ENTREGA (Resend)
   resend.com > Domains > Add Domain > institutofelipelopes.com.br
   Crie no Registro.br (Editar zona) os registros TXT/MX que o Resend mostrar e clique em Verify.
   API Keys > Create API Key > cole em RESEND_API_KEY na Vercel e faça Redeploy.
